# 🪐 Monografía: Los planetas más grandes

Monografía web sobre gigantes gaseosos y exoplanetas extremadamente grandes. Presenta a los 5 planetas que superan a Júpiter en tamaño, explicando su tipo, método de detección y datos curiosos, mediante un diseño responsivo construido con HTML, CSS y Bootstrap.

## Tecnologías utilizadas
- HTML5
- CSS3 (personalizado)
- Bootstrap 5

## 📌 Contenido
- Navbar de navegación
- Sección hero de introducción
- Grid de tarjetas (Cards) con información de cada planeta
- Modal con bibliografía
- Componentes personalizados: botones, badges, cards y modal con tema "neón espacial"
